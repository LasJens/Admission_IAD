# Intelligent Data Analysis — Project

This repository contains my project for the **Intelligent Data Analysis (IAD)**.

## Contents

- **IAD.ipynb** — Jupyter notebook with the project implementation
- **Проект ИАД.pdf** — project report (PDF)

## Project Description

**Decomposition algorithm for quasi-periodic oscillations**  
The project focuses on separating mixed signals into their components: **pulse, respiration, and random movements**. The following methods are used:

- Fourier transform
- Wavelet transform
- Neural networks
